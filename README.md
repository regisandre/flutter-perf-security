# flutter-perf-security

A Claude Code skill for measuring, optimising and hardening a Flutter app screen by screen on a real
Android phone: frame-timeline A/B harness, the fixes that paid off, the pitfalls, and a quick Android
security pass.

Install: copy `SKILL.md` to `.claude/skills/flutter-perf-security/SKILL.md` in your project (or to
`~/.claude/skills/flutter-perf-security/`).
